# 🍅 Pomodoro Timer

A clean, minimal Pomodoro Timer built with React and Vite. Helps you stay focused using the Pomodoro technique — 25 minutes of work, followed by short and long breaks.

🔗 **Live Demo:** [Logicflow-235.github.io/Pomodoro-Timer](https://Logicflow-235.github.io/Pomodoro-Timer)

---

## ✨ Features

- **3 modes** — Focus (25 min), Short Break (5 min), Long Break (15 min)
- **Animated SVG ring** that tracks your progress in real time
- **Session counter** — tracks how many focus sessions you've completed

- **Start / Pause / Reset** controls
- Clean blue dark theme
